# IAAC — Projetos

Projetos desenvolvidos na unidade curricular de Inteligência Artificial e
Análise de Dados. Cada projeto está numa branch própria:

- **Deteção de malware** — classificação de ficheiros benignos e maliciosos.
  [Abrir projeto](https://github.com/josediogocostamoreira-boop/IAAC/tree/feature/malware-detection)
- **Deteção de ransomware** — análise e classificação de amostras com foco em
  ransomware.
  [Abrir projeto](https://github.com/josediogocostamoreira-boop/IAAC/tree/feature/ransomware-detection)
- **Intrusion Detection** — exploração, preparação de dados e modelos baseline
  para deteção de intrusões.
  [Abrir projeto](https://github.com/josediogocostamoreira-boop/IAAC/tree/intrusion-detection)
- **Intrusion Detection Dataset** — classificação supervisionada de sessões
  de rede como normais ou intrusões, incluindo preparação e avaliação de modelos.
  [Abrir projeto](https://github.com/josediogocostamoreira-boop/IAAC/tree/intrusion-detection-dataset)

A branch `main` serve como índice dos projetos.
